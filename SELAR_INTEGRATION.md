# Selar Payment Integration for BAK55 Talent Platform

## Overview
This document describes the Selar payment integration that replaces Pesapal as the primary payment processor for the BAK55 platform.

## What's Been Implemented

### 1. **Edge Functions**
Three Supabase Edge Functions have been created:

#### `selar-initiate`
- **Purpose**: Initiates a payment with Selar
- **Input**: 
  - `amount` (number): Amount in KES
  - `email` (string): User's email
  - `product_type` (optional): Type of product (default: 'bakcoins')
  - `description` (optional): Transaction description
- **Output**: 
  - `payment_url`: Redirect URL for Selar checkout
  - `transaction_id`: Internal transaction ID
  - `reference`: Unique payment reference
  - `bak_coins`: Amount of BAKCoins to be credited

#### `selar-callback`
- **Purpose**: Webhook endpoint for Selar payment notifications
- **Handles**:
  - Payment status updates
  - Wallet crediting on successful payments
  - Transaction record creation
  - Email notifications to users

#### `selar-verify`
- **Purpose**: Manual payment verification (for admin use)
- **Allows**: Admins to manually verify and credit payments

### 2. **Database Changes**
Updated `payment_transactions` table with Selar-specific fields:
- `selar_transaction_id`: Selar's unique transaction identifier
- `selar_customer_id`: Selar customer identifier
- `selar_payment_link`: The checkout URL generated by Selar
- Default `payment_provider` changed to 'selar'

### 3. **Frontend Changes**
Updated `src/pages/BuyCoins.tsx`:
- Now calls `selar-initiate` instead of `pesapal-initiate`
- Updated UI to reflect Selar payment methods
- Payment flow redirects to Selar checkout page

## Selar API Endpoints Used

### Production
- **API Base URL**: `https://selar.co/api/v1`
- **Create Payment**: `POST /payments/create`
- **Verify Payment**: `GET /payments/{transaction_id}`

## Exchange Rate
- **20 KES = 1 BAKCoin**
- Minimum purchase: 100 KES (5 BAKCoins)

## Payment Flow

```
User → BuyCoins Page
  ↓
Enter Amount (KES)
  ↓
Click "Buy BAKCoins"
  ↓
selar-initiate Edge Function
  ↓
Create payment_transaction record (status: 'pending')
  ↓
Call Selar API to create payment
  ↓
Redirect to Selar checkout page
  ↓
User completes payment (M-Pesa/Card/Bank)
  ↓
Selar sends webhook to selar-callback
  ↓
Verify payment status
  ↓
Update transaction status
  ↓
Credit user wallet with BAKCoins
  ↓
Send confirmation email
  ↓
Redirect to success page
```

## Setup Instructions

### 1. Get Selar API Credentials
1. Create a Selar account at https://selar.co
2. Complete merchant verification
3. Navigate to Settings → API Keys
4. Generate your API keys:
   - Public Key (pk_...)
   - Secret Key (sk_...)
   - Webhook Secret (whsec_...)

### 2. Configure Secrets (Already Done ✅)
The following secrets have been added to the project:
- `SELAR_PUBLIC_KEY`
- `SELAR_SECRET_KEY`
- `SELAR_WEBHOOK_SECRET`

### 3. Configure Selar Webhook
In your Selar dashboard:
1. Go to Settings → Webhooks
2. Add webhook URL: `https://qtdxzgeeomgukkxfkwmh.supabase.co/functions/v1/selar-callback`
3. Select events to listen to:
   - `payment.success`
   - `payment.failed`
   - `payment.pending`
4. Save the webhook configuration

### 4. Test the Integration
Use Selar's test mode credentials to test:
1. Go to BuyCoins page
2. Enter amount (minimum 100 KES)
3. Complete payment using test card/M-Pesa
4. Verify wallet is credited

## Security Features

1. **Webhook Signature Verification**: Selar webhooks are verified using the webhook secret
2. **Idempotency**: Duplicate webhook calls are handled gracefully
3. **Transaction Status Tracking**: All status changes are logged
4. **Service Role Access**: Callback function uses service role for secure database operations

### Common Issues

**Issue**: Payment initiated but webhook not received
- **Solution**: Check Selar webhook configuration
- Verify webhook URL is correct
- Check Selar dashboard for webhook delivery status

**Issue**: Wallet not credited after successful payment
- **Solution**: Use `selar-verify` edge function to manually verify
- Check transaction status in `payment_transactions` table
- Review edge function logs for errors

**Issue**: Payment link not generated
- **Solution**: Verify Selar API credentials
- Check if Selar account is verified
- Review `selar-initiate` logs

```javascript
  }

```
